# Neknaj Circuit Game 2 のエディタ拡張

- [VS Code](vscode/README.md)
- [Neovim](nvim/README.md)
- [エディタの開発方針](https://github.com/neknaj/circuitgame2/blob/main/doc/development.md#neovim-と-vs-code-の拡張)

拡張の配布ファイルは、GitHub にログインして保存期間内に Actions の成果物からダウンロードする。

`fixtures/` のサンプルは、単独ファイルと複数ファイルのプロジェクトをエディタで検査するときに使う。
